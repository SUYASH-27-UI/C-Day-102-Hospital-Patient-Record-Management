# C Day 102 - Hospital Patient Record Management

## Description
A menu-driven C application to maintain basic hospital patient records using structures and file handling.

## Features
- Add new patient records
- Display all patient records
- Search patients using Patient ID
- Store records permanently in a text file
- Prevent duplicate patient IDs

## Files
- `patient.c` - Main C program
- `patients.txt` - Sample patient records

## Requirements
- GCC compiler

## How to Compile
```bash
gcc patient.c -o patient
```

## How to Run
On Windows:
```bash
patient.exe
```

Keep `patients.txt` in the same folder as the executable when running the program.

## Concepts Used
- Structures
- File handling
- Functions
- Searching
- Loops and switch-case
